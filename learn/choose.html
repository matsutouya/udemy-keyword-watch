売れるキーワードの選び方

Udemyでは、ジャンルが大きいほど売れるわけではありません。「Excel」のように大きな言葉には、評価が数千件ある先行講座（強豪）が何本もあり、後から出しても検索の上位に出ません。

反対に、「Claude Code Hooks」のように言葉を細かく分けると、受講者はいるのに講座が2本しかない場所があります。

手順

1. 大きなジャンルを1つ決める

自分が実際にやったことがあるジャンルから選びます。使い方と狙い目には、AI・デザイン・お金・語学など15ジャンルがあります。

2. ジャンルの中の細かい言葉を、点数で比べる

全キーワードの点数で、ジャンルを選び、強豪を「1本以下」に絞ります。需要ありのチェックを入れると、受講者がほとんどいない言葉は一覧から外れます。

3. キーワードのページで競合の講座を見る

受講者数の多い順に講座が並びます。1位の講座の受講者数が、合計のほとんどを占めているなら、1本の独り勝ちです。2位以下が薄いので、その1本と違う切り口なら入る余地があります。

4. 自分の講座の題名にそのキーワードを入れる

この点数は、題名にキーワードの語を含む講座だけを数えています。題名に入れないと、Udemyの検索で同じ言葉を探す人に見つかりにくくなります。

避けるとよい形

需要が大きいのに強豪が3本以上いる言葉（機械学習・Excel VBA・Python自動化など）は、点数が低くなります。

強豪が0本なのに受講者数の合計も少ない言葉は、競合がいないのではなく、探す人がいない可能性が高いです。評価数の合計が30件未満のものは、点数を25点以下に抑えてあります。
